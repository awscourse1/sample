# Infrastructure as Code

Configuration VPC, EKS, ECR et RDS avec Terraform
Sécurisation des ressources et accès

# CI/CD

Pipeline GitLab CI/CD avec étapes de build, test, scan, qualité, push et déploiement
Déploiement continu avec ArgoCD (approche GitOps)

# Containerisation et orchestration

Dockerisation de l'application Node.js
Configuration Kubernetes pour le déploiement et l'exposition des services

# Qualité et sécurité

Intégration de SonarQube pour l'analyse de code
Scan de vulnérabilités avec Trivy

# Monitoring

Configuration Prometheus pour la collecte de métriques
Dashboards Grafana pour la visualisation
Instrumentation de l'application Node.js

Cette architecture permet à FoodFast de bénéficier d'un déploiement automatisé, fiable et sécurisé, avec des outils modernes pour surveiller et améliorer continuellement la qualité de l'application.
